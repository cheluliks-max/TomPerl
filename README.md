# Мод «Том Пёрл» (Fabric, Minecraft 1.21.1)

Как получить .jar (без установки Java):
1. Зайди на github.com, создай новый репозиторий (кнопка New).
2. Нажми «uploading an existing file» и перетащи ВСЕ файлы из этой папки (вместе с папкой .github), нажми Commit.
3. Открой вкладку Actions -> дождись зелёной галочки у «build» (2-5 минут).
4. Открой этот запуск -> внизу Artifacts -> скачай tom_pearl_mod.
5. Внутри архива лежит tom_pearl-1.0.0.jar. Положи его в .minecraft/mods вместе с Fabric Loader и Fabric API для 1.21.1.

Игра:
- Крафт Фикалии: гнилая плоть + костная мука + земля -> 2 шт. Также есть в креативе (вкладка «Том Пёрл»).
- Съешь Фикалию -> 60 секунд «Режим Тома Пёрла»: Сила III, Скорость III, Сопротивление II, Регенерация II, Прыгучесть III, Спешка III, Огнестойкость, Поглощение IV.
- В этом режиме работают клавиши (меняются в настройках управления): Z – рывок, X – ударная волна, C – вонючее облако.
- Том Пёрл (яйцо призыва в креативе) сам находит выброшенные Фикалии, съедает их и получает те же баффы; правый клик Фикалией по нему тоже кормит его. Дерётся с враждебными мобами.
